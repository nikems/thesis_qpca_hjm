E3.1  EMBEDDING  C4 = blockdiag(C3, c),  rho4 = C4 / Tr(C4)
==============================================================================
   Choice: c = 0 (as Martin et al., Eq. 9). The basis state |11> (index 3) is then an eigenvector
   with eigenvalue 0 and Tr(C4) = Tr(C3), so rho4 restricted to the first 3 states IS rho3.
   martin_3x3: max|lambda(rho4)[0:3] - lambda(rho3)| = 0;  max_j 1-|<(u_j,0),u_j^(4)>|^2 = 0;  lambda_4 = 0, u_4 = [0.0, 0.0, 0.0, 1.0]
      purified input: probability of the padding state |11> = 0  -> never populated
      c = 0 (Martin, used here)  -> spectrum [0.7999, 0.1688, 0.0314, 0.0]   lambda's rescaled by Tr(C3)/(Tr(C3)+c) = 1.000
      c = Tr(C3)/1000            -> spectrum [0.7991, 0.1686, 0.0313, 0.001]   lambda's rescaled by Tr(C3)/(Tr(C3)+c) = 0.999
      c = Tr(C3)/3               -> spectrum [0.5999, 0.25, 0.1266, 0.0235]   lambda's rescaled by Tr(C3)/(Tr(C3)+c) = 0.750
      c = Tr(C3)                 -> spectrum [0.5, 0.3999, 0.0844, 0.0157]   (DOMINANT eigenvector becomes the padding state!)
   ecb_3x3: max|lambda(rho4)[0:3] - lambda(rho3)| = 0;  max_j 1-|<(u_j,0),u_j^(4)>|^2 = 0;  lambda_4 = 0, u_4 = [0.0, 0.0, 0.0, 1.0]
      purified input: probability of the padding state |11> = 0  -> never populated
      c = 0 (Martin, used here)  -> spectrum [0.86, 0.1339, 0.0061, 0.0]   lambda's rescaled by Tr(C3)/(Tr(C3)+c) = 1.000
      c = Tr(C3)/1000            -> spectrum [0.8592, 0.1337, 0.0061, 0.001]   lambda's rescaled by Tr(C3)/(Tr(C3)+c) = 0.999
      c = Tr(C3)/3               -> spectrum [0.645, 0.25, 0.1004, 0.0046]   lambda's rescaled by Tr(C3)/(Tr(C3)+c) = 0.750
      c = Tr(C3)                 -> spectrum [0.5, 0.43, 0.0669, 0.003]   (DOMINANT eigenvector becomes the padding state!)
   -> any c > 0 rescales every eigenvalue by Tr(C3)/(Tr(C3)+c) and adds a spurious eigenvalue c/(Tr+c)
      that can collide with lambda_2 (or even dominate). c = 0 is the only value that leaves the 3x3 problem intact.

   match Qiskit's native order 'q2 q1 q0', i.e. the PHASE bit is the LAST character, not the first one as the
   caption of Table VI says. The state of the 4th iteration hard-coded in the code is built from the counts
   of '100','101','110','111' = strings with q2 = 1: the projection was made on an EIGENVECTOR qubit
   (P(q2=1) = 0.576) instead of on the phase qubit (P(q0=1) = 0.414), and q0 was read as part of the vector.
